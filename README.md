# Landing page — Dra. Renata Dal Piva Buzin

Landing page responsiva para o consultório odontológico da Dra. Renata Dal Piva Buzin, em Chapecó (SC), com foco em contato e solicitação de agendamento pelo WhatsApp.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript puro
- Google Fonts: DM Sans e Playfair Display

## Como abrir

Abra `index.html` diretamente no navegador ou utilize um servidor local, como o Live Server do VS Code.

## Personalização

- WhatsApp e mensagem inicial: constantes no topo de `js/script.js`.
- Cores, fontes, largura e sombras: variáveis no topo de `css/style.css`.
- Conteúdo e seções: `index.html`.
- Fotografias futuras: pasta `assets/images`.
- Logotipo e ícone do navegador: `assets/images/logo-consultorio.png`.

## Informações pendentes

Antes da publicação, confirme diretamente com a profissional:

- CRO;
- procedimentos e especialidades divulgáveis;
- horários de atendimento;
- Instagram ou outros canais oficiais;
- fotografias e identidade visual.

Endereço informado para publicação: Rua Pequim, 933D, Passo dos Fortes, Chapecó (SC).

## Privacidade

Esta versão não possui formulário, banco de dados ou armazenamento de informações pessoais. Os botões apenas direcionam o visitante ao WhatsApp.
